## 1. 结构性问题：H-LM 存在混淆变量（最重要）

计划把 Whisper 与 Qwen3-ASR 的差异归因于**隐式 vs 显式 LM 解码器**。但两者之间同时变化的还有第二个变量：

> **Qwen3-ASR 被显式训练用于歌曲转写，Whisper 没有。**

计划自己在 §6.1 二和 §4 H-LM 依据里都写到了这一点，却没意识到它是混淆项。后果很直接：

- 若 Qwen3-ASR 泄漏更多 → 审稿人问："这是显式 LM 先验的副作用，还是它本来就被训练成要转歌词？" **计划无法回答。**
- 而这恰恰是计划认为"最有分量"的那条结论。§12 三称跨代对比"挡住了最致命的质疑"——实际上它引入了一个新的。

**修复（低成本，且顺带解决问题 2）**：加入第三个模型族——**有显式 LLM 解码器、但未针对歌曲训练**的模型。`Do LLM Decoders Listen Fairly?` 用的 **Granite-speech 2B→8B** 正好合适，且该文已验证其可跑通。三族两两对照即可解耦：

| | 显式 LLM 解码器 | 歌曲训练 |
|---|---|---|
| Whisper (3 档) | ✗ | ✗ |
| **Granite (2 档)** | **✓** | **✗** |
| Qwen3-ASR (2 档) | ✓ | ✓ |

Whisper↔Granite 差异 = 解码器类型的效应。Granite↔Qwen3-ASR 差异 = 歌曲训练的效应。**只需推理，不需新方法**，与 Fig 2 现有流程完全复用。

## 2. Fig 2 当前是 3 点 vs 2 点，且两族不可比

即使不考虑上面的混淆，把它叫"缩放曲线"也很脆弱：

- Whisper 244M / 769M / 1550M；Qwen3-ASR 约 780M / 2B。**规模区间不重叠**，训练数据完全不同。
- 两点连成的"曲线"不足以支撑趋势断言。

**叙事上的修复**：不要画成单张 scaling law。改为报告 **(a) 族内趋势 + (b) 族间落差**，并明说规模不可比。加入 Granite 后变成 3+2+2，族间对照才是真正的证据来源，规模只是次要维度。

## 3. §6.1 "mel 前端完全一致"被高估了

核查发现 AuT 编码器做 **8 倍下采样，输出 12.5Hz token rate**；Whisper 编码器是 **50Hz**。**时间分辨率差 4 倍。**

- 对 Fig 1/2（只看输出文本）：无影响，mel 一致的论点仍成立。
- 对 **Fig 3 逐层探针：有影响**。跨架构比较"第 k 层"时，两者每层覆盖的时间跨度不同，逐层曲线不能直接叠加。需要按相对深度（layer/total）归一化，并在时间轴上对齐后再比。
- §6.1 "无需'输入不可比'的免责声明"这句**要删掉或限定到 Fig 1/2**。

另：mel 参数逐项相同（n_fft=400 / hop=160 / Hann / Slaney / 0–8kHz）这一条建议**直接 diff 两边的特征提取代码确认**，20 分钟的事，但 §6.1 整段论证都压在它上面。技术报告只写了 128-dim Fbank。

## 4. §5.4 与 MIR-1K 实际不符（具体冲突）

- §5.4 规定片段长度 **10–30 s**。
- MIR-1K 实际每段 **4–13 s**（全库共 133 分钟 / 1000 段）。

两者冲突。要么放宽到 4–13 s，要么拼接多段——但拼接会引入切换点，反而制造新的混淆。**建议放宽，并在论文中说明长度分布。**

## 5. 把 MUSDB18-HQ 移出关键路径

§11 把"数据集审批"列为最高风险，但两个数据集的地位并不对等：

- **MIR-1K 单独就能撑起 C1–C4 全部四个条件、中—中语种组合、以及 H3（计划自称"最干净的实验"）。**
- MUSDB18-HQ 只服务于中—英语种组合，即 H4。

所以：**MIR-1K 是关键路径，MUSDB18/H4 是可延后分支。** 若 MUSDB18 审批卡住，砍掉 H4 即可成篇，不影响主结论。这条应该写进 §9.3 那种风险隔离段落里。

## 6. 探针的说话人划分偏薄

MIR-1K 只有 **19 位演唱者**。Fig 3 要求"按歌曲/说话人划分训练测试"，19 人做说话人无关划分样本很少，探针精度容易被个体差异带偏。建议：报告 per-singer 方差或用 leave-one-singer-out，别只给单一准确率。

## 8. 次要项

- **LLR 指标**需明确 n-gram 阶数，中文建议用字级；C1（纯器乐）天然是假阳性率对照，应在论文里**显式**作为 FP baseline 报告，别只当基线条件。
- **Whisper 的幻觉是混淆项**：`Do LLM Decoders Listen Fairly?` 报告 Whisper 在静音注入下会触发幻觉。需要把"幻觉出的文本恰好像歌词"和"真的转了歌词"分开——C1 对照能覆盖，但要写明。
- **H-LM 的新颖性不对称**：该文已发现 Qwen3 在准确率与公平性上均优于 Whisper。若结果落在"显式 LLM 泄漏更少"，审稿人会读作"确认已知方向"，分量弱于 H-LM 成立的情形。§11 把两个方向都写成"好结论"，实际不对等——**准备好落在弱的一侧时怎么讲故事**。
